
# vuminhluan.github.io

## Development

```bash
npm ci
npm run dev
npm test
npm run build
```

`npm run dev` rebuilds Pug and Tailwind sources, serves the repository root, and live-reloads changed HTML, CSS, JavaScript, and images. `npm run build` regenerates the deployable `index.html`, `en.html`, and `assets/css/style.css` files.

Vietnamese is available at `/`; English is available at `/en.html`. These generated files remain committed so the existing GitHub Pages deployment continues to work.
permalink: /index.html
